# Preferences

Curated and public-safe. The agent may propose edits; review them before
committing.

## Working style
- Be direct and concise. Skip praise, filler and restating the request.
- Prefer the smallest working change. No speculative abstractions or options.
- Ask before adding a dependency or rewriting unrelated code.
- Run the project's formatter, linter and narrowest test before calling work done.

## Stack
- Rust, TypeScript/JavaScript, Python, Nix, Podman/Docker.
- Linux; bash and Python for repository scripts.

## Writing
- Reports: formal academic English, citations preserved, no first person, no AI
  filler.
- Use the `humanize` skill for ODT reports. Its voice profile is provisional.

## Safety
- Never commit secrets, `.env`, service passwords, memory, session logs or client
  data.
- Ask before destructive git or filesystem commands.
